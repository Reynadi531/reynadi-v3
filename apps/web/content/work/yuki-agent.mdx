Yuki Shiina is a quiet, robot-loving Computer Engineering student, and the persona of an AI assistant built for a cloud computing course. The interesting part is not the chat; it is everything that keeps it running.

## The brief

Build an AI service and run it the way production services run: containerised, health-checked, isolated, and delivered by a pipeline rather than by hand.

## The agent

A FastAPI app exposes `POST /ask`, which routes each question through a Google ADK agent on Gemini 2.5 Flash with session handling. CORS is locked to the frontend's origin, and `/health` and `/ready` back the Kubernetes probes.

## Shipping it

- A multi-stage Alpine Docker image, built and pushed to GHCR by GitHub Actions, with a Jenkinsfile as an alternative pipeline.
- A Kubernetes deployment with a security context and probes, a ClusterIP service, and an NGINX ingress with TLS.
- A network policy to isolate the pod and a pod disruption budget to keep it available during maintenance.
