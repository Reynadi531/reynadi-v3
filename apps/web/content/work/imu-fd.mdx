Fall detection research lives or dies on clean motion data. IMU-FD is the instrument behind it: firmware that reads an IMU, corrects it, and gets every sample off the device without dropping it.

## The problem

Raw IMU readings drift and carry sensor bias, and a lost packet can hide the exact moment of a fall. The device needed to be calibrated, observable, and able to keep a backup of everything it sent.

## Calibration first

The work started with a Python calibration tool for the GY-85 sensor: a desktop GUI that connects over serial and walks through accelerometer and gyroscope calibration, backed by a Jupyter notebook for analysis.

## The firmware

The current firmware runs on an ESP32 with an MPU6500.

- Streams CSV samples over ESP-NOW to a receiver sketch acting as the ground station.
- Logs the same payloads to microSD under `/IMU_DATA/`.
- Runs calibration on the device and persists it, Wi-Fi credentials, and the ESP-NOW peer to EEPROM.
- Shows live status on an SSD1306 OLED.

## Operating it

The device joins Wi-Fi, with Bluetooth Serial as a fallback for provisioning, and exposes an HTTP control API on port 80 documented as an OpenAPI spec. Researchers can start and stop streams, recalibrate, manage SD logging, and set the peer without reflashing.
